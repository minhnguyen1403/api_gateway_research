# API Gateway Research – Microservices Architecture

## 📌 Overview
This repository contains a **research and experimental implementation of the API Gateway pattern** within a **microservices architecture**, developed as part of an **academic research / graduation thesis**.

The project demonstrates how an **API Gateway** acts as a single entry point for client requests and manages communication between multiple backend microservices.

---

## 🎯 Research Objectives
- Study the **API Gateway pattern** in microservices architecture
- Implement request routing between clients and microservices
- Analyze the role of API Gateway in:
  - Decoupling clients and services
  - Centralized access control
  - Simplified client communication
- Serve as a practical backend research project
